## Scope and compatibility

Visible Collection creation and note-addition actions, inline Organizer Collection/subheading drafts, exact Review → Save and protected Undo, preserved primary placement, Collection-scoped search and return navigation, saved-note filing recovery, final note-write guards, and bounded recovery discovery are included.

Store/base format is 17, portable envelope 7, saved views component 2, same-vault recovery 13, device-local history 5 and return-navigation history 2. Workspace remains 3. Supported earlier formats remain readable, including version-4 interrupted Undo journals. The new barriers prevent older builds from silently broadening Collection searches. Update all syncing devices to 0.24.0. An older build protects newer organization read-only; a writable downgrade requires matching earlier plugin assets and a complete compatible pre-upgrade organization backup. Replacing runtime files alone is not rollback.

Ordinary organization never moves, renames or rewrites Markdown. Explicit note creation/append/template/attachment workflows write their reviewed files; the existing separately reviewed ENT proposal-promotion and canonical-placement exceptions also remain available. Covers remain local-vault only; no dependency, network permission, analytics or online-image loading is added. The user's main vault is not an installation target for this publication.
