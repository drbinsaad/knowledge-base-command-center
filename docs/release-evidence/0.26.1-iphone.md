## Scope and privacy

Data-safety and reliability fixes: an existing readable, recognized `data.json.bak` is copied to `data.json.bak-kept-<timestamp>` when `data.json` is missing at startup (organization stays read-only if the backup cannot be inspected or copied); plain Sync & recovery wording about where organization is stored and how to check sync on each device; typed text kept in Quick Append and Library editors after an unchanged Sync reload; single execution of simple dialogs; no rendering or listeners after the command center closes while loading; heading rewrite limited to the real top-level heading; 44-point targets and kept indentation in iPad split view; readable detail labels; release checksum verification and a wider leaked-path check; development-dependency audit fix.

Minimum Obsidian remains 1.13.0. Data formats, command IDs and the plugin ID are unchanged. No dependencies, analytics, network permissions or online-cover support are added.
