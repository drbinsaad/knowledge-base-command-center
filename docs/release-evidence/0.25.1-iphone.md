## Scope and compatibility

Long related-note titles, external backlink filenames and IDs wrap within their rows. IDs reflow below titles when space is limited, including the narrow desktop inspector. Rows override single-line/fixed-height host button defaults without clipping text, retain touch targets and mixed-direction labels, and preserve existing click/keyboard handlers. Long selected-note headings also wrap after following a related note. The phone/tablet header remains fixed; no body-level clipping workaround is added.

No note content, organization, settings, command identity, dependency, network permission or online-cover behavior changes. Store/base format 17, portable envelope 7, saved views component 2, recovery 13, device-local history 5, return-navigation history 2 and Workspace 3 are unchanged. Obsidian 1.13.0 remains the minimum.

## Supplemental implementation evidence

Before assigning release metadata, Node 22.23.2 passed `npm run review`: 1,462 runtime tests with coverage, three performance-budget tests, ten release tests, strict typechecking, zero-warning lint/JSON validation, build, bundle-size and Community checks. `npm run test:layout` passed 297 cases (157 Chromium, 140 WebKit), with zero failures or skips.

The twelve new relationship cases cover 320/390 phone, 820 portrait tablet, 1180 landscape tablet, 600 split-view and 1440 desktop-side-panel layouts. They measure actual text-line bounds and scroll widths, long unbroken IDs, Arabic text, fixed-height/nowrap host buttons, touch targets, fixed mobile header, external-file opening, keyboard selection, long selected headings and Back/focus restoration. A negative control using the original stylesheet fails at 320 pixels with content extending to 3,133 pixels. The patched cases all pass; hidden scrollbars alone cannot satisfy their text-containment assertions.

A disposable synthetic-vault smoke check in Obsidian 1.14.2 on macOS loaded the implementation build and invoked the production related-row renderer under native Obsidian CSS. A 388-pixel detail body had a 388-pixel scroll width; every tested text line fit, and rows retained at least 44-pixel heights. No captured renderer errors or console warnings/errors were reported. The temporary DOM preview was removed and the test vault's previous runtime assets restored and byte-compared. No main-vault installation or note editing occurred. This is a native desktop CSS smoke check, not a full-device or full-native-navigation pass.
