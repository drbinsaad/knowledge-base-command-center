## Scope and compatibility

This candidate adds kept-copy discovery, preview and guarded restore-as-new; strengthens backup preservation, conflict-copy verification, rename recovery and device-local Undo binding; reviews setup Inbox changes and imported-entry linking; improves attachment destination checks, collision handling and copied-file recovery; clarifies removal and Undo; and fixes measured unnecessary work in folder menus, backlinks, search and placeholder queues. Touch, focus, text composition, cover status and the custom Bases view have additional regression coverage. Existing Collection create/add/organize workflows were regression-tested.

Minimum Obsidian remains 1.13.0. The stable plugin ID and command IDs are unchanged. Shared store/base format 17, portable package 7, portfolio 1 and recovery 13 are unchanged. Device-local envelope 5 now has optional organization-history bindings: old or mismatched history may reset, preserving notes and organization. Rename journal format 2 remains at its existing local key; version-1 journals remain readable. An older plugin encountering an unfinished newer journal can enter protected recovery. Returning through an older writer can discard history bindings and cause another reset after updating.

No runtime dependency, analytics, network access or online-cover capability is added. Automated test fixtures are synthetic; release assets contain no vault notes, plugin data or recovery copies. Restore-as-new does not restore missing Markdown notes or attachment files.
