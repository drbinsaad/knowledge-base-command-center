## Scope and privacy

Compact desktop header, collapsible Details/Filters, a selected-note attachment list, collapsible ordinary note metadata and adjustable detail width. Phones and tablets retain full-width details by default; a wide tablet can explicitly opt into split view. Width preferences are device-local and do not enter synced organization or Undo.

Attachments are projected from cached internal links, embeds and recognized property links, with local cover handling. Listing does not read binaries, render note bodies, download files or change notes. Opening rechecks the existing vault file and delegates to Obsidian. Availability of a native file handler is device-dependent.

Minimum Obsidian remains 1.13.0. Synced store/base format 17, portable envelope 7, saved views component 2, recovery 13, device-local history 5, return-navigation history 2 and Workspace 3 are unchanged. No dependencies, analytics, network permissions or online-cover support are added.
