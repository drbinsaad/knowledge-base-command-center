## Scope and compatibility

Multi-file attachments of any type with a Show in note choice (preview images, PDF, audio and video; link other types; or embed/link every file), pre-copy link checks, vault-root folder handling, the setup wizard changes and Run setup again…, plain-language command names and notices, and desktop header placement of Arrange/Edit and Undo are included. Independent review added duplicate-submission protection, stale/ENT setup guards and narrow-desktop Undo visibility. The unrelated-note redraw optimization was withdrawn because external backlinks and in-flight searches require those refreshes.

Store/base format 17, portable envelope 7, saved views component 2, same-vault recovery 13, device-local history 5, return-navigation history 2 and Workspace 3 are unchanged from 0.24.0. Command IDs are unchanged; only visible names changed. No dependency, network permission, analytics or online-image loading is added. Ordinary organization never moves, renames or rewrites Markdown; Attach file writes only the files and links the user explicitly chooses.
