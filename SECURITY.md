# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put vault data at risk. Use GitHub's private vulnerability reporting for this repository instead.

Include the affected plugin version, Obsidian version, operating system, reproduction steps, and the potential effect on vault data. You should receive an acknowledgement within seven days.

## Scope

Knowledge Base Command Center operates inside the current Obsidian vault. It does not intentionally make network requests, collect telemetry, or access files outside the vault. Reports about unintended note modification, deletion, path traversal, unsafe imported configuration, or disclosure of vault data are in scope.
